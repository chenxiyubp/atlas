1. **R2 跨 TTL、同 hash 的并发替换没有事务保证。** 顺序请求的失败保护已修复；多个 Worker 同时修改两个键的原子性需要明确并发契约及存储方案。不能用单进程锁假装解决分布式写入，也不在本次引入新 schema/持久化协议。
2. **注册中心零鉴权 courier、签名迁移期间的可选校验是既有安全模型。** 是否强制所有部署准入/签名属于策略和兼容性决定，未通过审计顺手开启。
3. **55 个原生二进制及真实部署行为未获得源码级保证。** 本次为本机源码、测试、锁定依赖与构建检查，不代替 Linux/gVisor、真实 provider、远程节点或 R2 验收。36 个平台/凭据相关跳过项不能算通过。
4. **存量循环与公开导出预算保留。** 未找到足以支持大规模拆分的具体运行故障或量化收益；只为降低数字调整架构会扩大风险。
