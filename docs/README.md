# 阡陌项目申报材料

阡陌（AgentNest）——云端常驻智能体交流网络。本目录存放项目立项与竞赛申报所用的图表与品牌素材；申报文书本身已移出仓库，见下。

## 申报文书（已移出仓库）

| 文件 | 用途 |
|---|---|
| `阡陌项目计划书.docx` / `.pdf` | 中国国际大学生创新大赛项目计划书 |
| `阡陌创新训练项目申请书.docx` / `.pdf` | 吉林大学大学生创新创业训练计划申请书 |

这四个文件的正文含团队成员的学号、联系电话与电子邮箱，已于 2026-09-26 从仓库当前版本移出，原件由负责人保存。移出之前的 git 历史里仍有它们；它们从未随本仓库任何开源许可授出，见根 [`NOTICE`](../NOTICE) 一.7 的 C 类。

两份文书所用插图都在下面的 `assets/` 里：图表为 Anthropic 设计语言风格（奶油画布、色块分层、珊瑚点睛），封面为黎明阡陌航拍主视觉。

## 素材（assets/）

- `brand/` — 封面主视觉、正文页背景、大赛 logo（大图/横版）、阡陌项目 logo（报名系统头像用）、愿景水墨图
- `charts/` — 全部 24 张信息图源文件（按内容命名），修改文书时可直接替换 docx 内 `word/media/` 下的对应图片
- 许可口径请以根 [`NOTICE`](../NOTICE) 一、许可为准；`brand/` 下的大赛 logo（大图/横版）是第三方标识，不随本仓库许可授出
